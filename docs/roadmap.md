# Roadmap

## Phase 1 — POC
- Deploy Postiz in Docker
- Connect one test social account
- Create mock publisher
- Test 10–20 scheduled posts
- Verify retry, token handling and duplicate prevention

## Phase 2 — MVP
- Build content database
- AI topic generation
- Master-draft generation
- Platform-specific variants
- Review queue
- 100–200 posts/week

## Phase 3 — Scale
- Image API
- Semantic duplicate detection
- More social accounts
- TikTok / YouTube integration
- 300 posts/week

## Phase 4 — Target
- 500 posts/week
- Analytics feedback loop
- AI topic optimization

## Scale rule
Do not jump directly to 500 posts/week. Increase only after duplicate rate, factual error rate, API failures and token refresh stability are within acceptable thresholds.

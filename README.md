# AI Social Content Automation

AI 驅動的多平台社群內容自動化專案。

## 目標
- 每週管理約 500 則社群內容
- 支援約 13 個社群出口：
  - Facebook：約 7 個
  - YouTube：2 個
  - Instagram：1 個
  - TikTok：2 個
  - Threads：1 個
- 建立 AI Content Engine + Social Publisher 架構
- 以 Postiz 為第一候選發布引擎，BrightBean Studio 為第二候選

## 核心架構
1. 內容來源：官網、行程、講座、FAQ、旅遊知識
2. AI 選題與母稿
3. 平台差異化改寫
4. 語意查重與風險檢查
5. 圖片／影片素材匹配
6. 排程與官方 API 發布
7. 成效回收
8. AI 下一輪選題

## 開發策略
- Phase 1：MVP（100～200 則／週）
- Phase 2：多平台與圖片
- Phase 3：高自動化（300～500 則／週）
- Phase 4：成效學習與內容優化

詳見 `docs/`。
